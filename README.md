# Java 1

A repository for introductory Java programming exercises.

## Requirements
- A Java Development Kit (JDK) compatible with the source code

## Run
Compile and run a Java source file from the repository root:

```bash
javac Example.java
java Example
```

Replace `Example.java` and `Example` with the actual source filename and class name. Review the repository for any build configuration.

## Topics
Consult the source files for the Java concepts and exercises included.
